# Retrieval-Augmented Generation (RAG) Overview


> RAG combines a vector database with an LLM for improved Q&A


## Content


RAG (Retrieval-Augmented Generation) combines a vector database with an LLM. Instead of relying on
the model's parametric memory, RAG retrieves relevant documents at query time and injects them into
the prompt context. This grounds the LLM's answer in actual source material, dramatically reducing
hallucinations and enabling Q&A over private or up-to-date knowledge.
